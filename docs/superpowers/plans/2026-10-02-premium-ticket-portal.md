# Plan de implementación — portal premium de tickets

1. Inspeccionar OpenAPI, contratos, roles, errores y datos demo del backend.
2. Definir dirección visual, tokens, tipografía e imágenes responsivas.
3. Construir transporte HTTP, sesión, RBAC, validaciones y pruebas unitarias primero.
4. Implementar shell público, autenticación y páginas informativas.
5. Implementar portal cliente: dashboard, tickets, detalle, adjuntos, FAQ, asistente y perfil.
6. Implementar experiencias de asesor y supervisor, incluidas asignaciones, contenido, SLA, reportes y auditoría.
7. Verificar tipos, lint, unitarias, flujos E2E y respuestas del API real.
8. Capturar vistas a 1440, 1024 y 390 px; corregir clipping, contraste y densidad.
9. Documentar arquitectura, rutas, sistema visual, endpoints y gaps.
10. Ejecutar revisión final de calidad y repetir la evidencia después de cualquier corrección.
